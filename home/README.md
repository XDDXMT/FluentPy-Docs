# FluentPy 展示主页

`dist/` 使用普通 HTML、CSS、JavaScript 与 FluentPy 工作台的实际运行截图。首页收录项目介绍、组件预览、安装入口、跨平台示例与作者简介。

在文档仓库根目录运行 `python preview_site.py`，然后打开 [本地首页](http://127.0.0.1:8768/)。完整站点同时提供 `/docs/`，旧的 `/#/...` 文档链接会跳转到新路径。

`package_site.py` 将 `home/dist/` 与文档仓库根目录的 `dist/` 合成完整网站。预览和部署步骤见 [文档仓库说明](../README.md#部署)。
